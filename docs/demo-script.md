# QuantOS 60–90 Second Demo Script

1. Run `quantos start --demo` and open the printed loopback URL.
2. Point out **DEMO DATA**, the synthetic-data label, version, and build commit.
3. On Overview, show exact capability availability rather than a binary health
   light.
4. Open Ask and submit the prepared market question. Show facts, limitations,
   reason codes, and references.
5. Select **Why this answer?** and inspect the structured QueryPlan,
   capabilities, cutoff, and trace. Do not describe it as model reasoning.
6. Open Analytics, query close by trading date, and show the line chart plus
   exact table values.
7. Open Data Provenance and show dataset references, provider, registry
   versions, and cutoff.
8. Open Replay and explain retrospective effective truth versus strict
   operational knowledge. Show zero PIT violations and the limitations list.
9. End on the message: QuantOS is an auditable research workspace, not a stock
   predictor or trading bot.
