1. Export the accepted content snapshot onto independent Public history.
2. Run Python, frontend, security, and Docker gates from the Public branch.
3. Review the complete public diff and Public CI.
4. Make a separate release decision; do not tag during synchronization.

- Phase 8A.3 public HTTPS deployment with an external ingress boundary;
- Phase 8A.4 external user testing and product-discovery evidence.

Auth, BYOK, Billing, expanded AI-BI, or other product work requires observed
user need. None is implied by this roadmap.
