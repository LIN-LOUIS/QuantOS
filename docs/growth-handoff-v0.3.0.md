# QuantOS v0.3.0 Growth Handoff

## Positioning

QuantOS is an **Auditable Financial Research Workspace** for local,
evidence-aware Chinese A-share research. It is not a stock predictor, trading
bot, or recommendation engine.

## Demo command

```bash
quantos start --demo
```

Demo Mode is offline, deterministic, synthetic, and visibly labeled.

## Ideal early users

- Individual researchers who need traceable market facts
- Analysts evaluating PIT and provenance discipline
- Small research teams testing local-first AI-assisted workflows
- Technical pilot users who can provide structured product feedback

## Top demo workflows

1. Review capability availability before asking a question.
2. Ask a market question and inspect facts, limitations, and Why this answer.
3. Run bounded analytics and inspect the table, chart, and provenance.
4. Compare strict operational and retrospective replay semantics.

## Known limitations to disclose

- Local service with no production authentication
- Synthetic fixture data in Demo Mode
- Strict operational history still accumulating
- Historical Evidence and Knowledge depend on PIT-valid persisted coverage
- Provider availability and rate limits vary
- Research use only; not investment advice

## Feedback to collect

- Did the user reach a useful result without architecture knowledge?
- Which availability or reason-code explanations were unclear?
- Did provenance and trace increase trust or add friction?
- Which repeated workflow required manual steps?
- What prevented the user from returning for a second session?
